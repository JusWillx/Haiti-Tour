# Reflection draft — review before submitting

For this project, I chose to make a Haiti history tour because my Haitian background is important to me, and I wanted the assignment to connect with something personal. I also wanted it to relate to cybersecurity by showing why checking sources and validating information matters. The tour focuses on the Citadelle, Sans-Souci, and an overview of the National History Park. I requested the Haitian flag colors so the interface would reflect that connection.

AI helped adapt the starter code, organize the three stop records, and add a Slow Tour button. That button changes camera transitions from two seconds to six seconds, giving users more time during the journey. The project also includes a practice-flight mode using the supplied movement code. I need to review these changes and understand how the navigation, validation, and elapsed-time calculation work before presenting them.

The automated missing-data exercise removed a historical source from a temporary copy. The validator reported “missing source,” and the data test failed. Restoring the source made the test pass again. This reinforced the importance of fixing incomplete information instead of hiding a warning.

One limitation is that the simulation has no terrain or realistic aircraft physics. Coordinates are approximate, and the park reference point is not an exact monument location. Automated checks passed, but browser rendering and partner feedback still need to be completed and documented honestly.
